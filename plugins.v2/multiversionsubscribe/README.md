# 多版本订阅（MultiVersionSubscribe）

> MoviePilot V2 插件。为**指定的订阅**按**多选的画质规格**（1080p / 4K / 杜比视界 / REMUX …）
> 分别下载，多个版本同时保留，不受出种顺序和洗版优先级限制。

## 1. 为什么需要它

MoviePilot 原生订阅只有两种形态：

| 形态 | 行为 | 问题 |
| --- | --- | --- |
| 普通订阅 | 每个剧集只下载**一个**最符合过滤条件的资源 | 只能留一个版本 |
| 洗版（best_version） | 按优先级不断替换成**更好**的那一个 | 最终仍然只有一个版本；老剧优先级已到顶，洗不动 |

如果你的需求是「同一个剧，1080p、4K、杜比视界我都要，出哪个下哪个，下完就删、不入库不刮削」，
原生订阅做不到。本插件用**独立的规格维度 + 独立的下载进度记录**解决这个问题：

- 画质规格像 MP 自带的过滤规则组一样**直接多选**，不用手写正则；
- 每个规格**单独判断、单独下载、单独记进度**，先出 4K 再出 1080p 也没关系（无关出种顺序）；
- 同一个订阅下，**同一种子只会下载一次**（一个 4K 杜比视界发行同时命中「4K」和「杜比视界」时不会下两遍）；
- 站点、过滤规则组、包含/排除、自定义识别词**全部沿用订阅自己的配置**，插件只负责「画质规格」；
- 下载状态记在插件内部，**不依赖媒体库**，所以「下载后删除 / 不入库 / 不刮削」同样可用；
- **每个订阅可以有自己的规格**：A 剧配 `4K+DV`，B 剧只配 `1080p`（留空则用默认规格）；
- **组合规格**（如 `4K+DV+60FPS`）表示条件**同时满足**，一个组合就是一个版本；
- 电视剧严格按订阅的**开始集数 ~ 总集数**下载，范围之外的剧集不会下载；
- 执行周期可**跟随系统**（取系统「订阅搜索间隔」与「RSS 间隔」中更短的一个），也可直接选固定周期。

## 2. 安装

### 方式一：自定义插件市场（推荐）

1. 仓库根目录保持如下结构：

   ```
   ├── package.v2.json
   ├── icons/
   │   └── torrent.png
   └── plugins.v2/
       └── multiversionsubscribe/
           ├── __init__.py
           └── README.md
   ```

2. 在 MoviePilot 的「设置 → 插件市场」里把这个仓库地址加入插件市场源。
3. 在插件市场搜索「多版本订阅」安装。

### 方式二：本地目录安装

把 `plugins.v2/multiversionsubscribe` 整个目录复制到 MoviePilot 的插件目录：

- Docker：`./config/plugins/multiversionsubscribe`
- 源码运行：`app/plugins/multiversionsubscribe`

然后重启 MoviePilot，或在「插件」页面点「重载插件」。

> 目录名必须是 `multiversionsubscribe`（类名的小写），类名必须是 `MultiVersionSubscribe`。

## 3. 使用步骤

### 3.1 先建好订阅（在 MoviePilot 原生订阅页面）

- **只填「订阅站点」**；
- **过滤规则组、包含、排除照常填**（插件会沿用）；
  - 填了就用订阅自己的；没填时按宿主原生逻辑回退到「设置 → 订阅默认过滤规则组」（洗版订阅回退到「洗版默认过滤规则组」）。
- **质量 / 分辨率 / 特效不要填**（这些由插件接管）。

### 3.2 再配置插件

打开「插件 → 多版本订阅 → 设置」：

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 发送通知 | 有下载时发一条插件消息 |
| 接管订阅（暂停原生搜索） | **建议开启**。开启后插件会把所选订阅置为「暂停」，避免原生订阅重复下载；需要还原时点详情页的「恢复订阅状态」 |
| 保存后立即运行一次 | 保存配置后 3 秒自动跑一轮，方便验证 |
| **执行周期** | 「跟随系统」= 取系统「订阅搜索间隔」与「RSS 间隔」中更短的一个；也可直接选 5/10/15/30 分钟、1/2/6/12/24 小时 |
| 下载器 | 留空用默认下载器 |
| 保存目录 | 留空用媒体默认下载目录；建议单独指定一个下载目录，方便配合清理插件 |
| 要接管的订阅 | 多选，从现有订阅里挑 |
| **默认画质规格** | **多选**，选几个就下几个版本；未单独配置的订阅都用它，见 3.3 |
| **组合规格** | 可选。一行一个，用 `+` 连接多个预设，表示**同时满足**，见 3.3 |
| 每个订阅的「单独规格」 | 加入订阅并保存后重新打开本页才会出现；留空 = 用默认规格 |
| 自定义规格 | 可选。预设不够用时再自己写，见 3.4 |
| 同一规格下载所有匹配资源 | 默认关闭：每个规格只下**第一个没下过的**。开启后：所有匹配且没下过的都下（可能很多，慎用） |
| 下载完成后自动删除任务及文件 | **危险**：下载完成后自动删任务+文件，不可恢复。默认关闭 |

> **执行周期**默认为「跟随系统」：取 MoviePilot「设置 → 订阅」里「订阅搜索间隔」与「RSS 间隔」中
> **更短**的一个（当前值会显示在配置页和详情页），也可以在插件里直接选固定周期。
> 想立刻执行就点详情页的「立即运行」或发命令 `/mvsub`。

### 3.3 画质规格（默认规格 / 组合规格 / 每个订阅单独配置）

在「画质规格」里勾选即可，关键词取自 MoviePilot 内置过滤规则，匹配时忽略大小写：

| 预设 | 含义 | 作用字段 |
| --- | --- | --- |
| 1080p | `1080p` / `1080i` / `x1080` | 分辨率 |
| 4K | `4K` / `2160p` / `x2160` | 分辨率 |
| 720p | `720p` / `720i` / `x720` | 分辨率 |
| 杜比视界（Dolby Vision） | `Dolby Vision` / `DOVI` / `DV` / 杜比视界 | 特效 |
| HDR | `HDR` / `HDR10` / `HDR10+` / `HDRVivid` | 特效 |
| 杜比全景声 | `Atmos` / `杜比全景声` | 特效 |
| REMUX | `REMUX` | 质量 |
| Blu-ray | `Blu-ray` / `BluRay` | 质量 |
| WEB-DL | `WEB-DL` / `WEBRIP` | 质量 |
| UHD | `UHD` / `UltraHD` | 质量 |
| H265/HEVC | `H.265` / `HEVC` | 质量 |
| 中字 | 中字 / 简中 / 繁中 / 简体 / 繁体 / chs / cht | 包含 |
| 特效字幕 | `特效` | 包含 |
| 60FPS | `60fps` / `60帧` | 特效 |

举例：同时勾选「1080p」「4K」「杜比视界（Dolby Vision）」，那么这三种版本只要有资源就会各自下载一份。

#### 组合规格（条件同时满足）

「默认画质规格」里每个预设是**一个独立版本**（条件之间是「或」）。
如果想让「4K + 杜比视界 + 60FPS **同时满足**」才算一个版本，在「组合规格」里写：

```
4K+DV+60FPS
4K杜比全景 = 4k+atmos
```

- 一行一个组合，用 `+`（也支持 `&`、`,`、`、`）连接多个预设；
- 组合名可以省略，省略时自动用 `4K+DV+60FPS` 这样的短名；想自定义就写 `名字 = 4k+dv`；
- 组合规格会自动出现在「默认画质规格」和每个订阅的「单独规格」下拉框里，直接勾选即可；
- 组合内部是**正则前瞻**实现的「与」关系：标题里必须同时出现 4K、DV、60FPS 才会命中。

#### 每个订阅单独配置

1. 先在「要接管的订阅」里选好订阅并保存；
2. 重新打开本页，列表下方就会出现每个订阅的「单独规格」下拉框；
3. 给某个剧单独勾选规格（预设、组合规格、自定义规格都可以）；
4. 留空 = 使用上面的「默认画质规格」。

#### 集数范围

电视剧只下载订阅「开始集数 ~ 总集数」范围内的剧集：

- 订阅设了「开始集数 = 40、总集数 = 50」，那么 1-39 集的资源（单集或合集）会被直接跳过；
- 一个 1-50 的整包只会记录并请求 40-50 集（下载器是否按集选择文件取决于下载器本身）；
- 每个规格独立记录已下载的集数，重复运行不会重复下载。

### 3.4 自定义规格（可选）

预设不够用时，可以在「自定义规格」里补充，**每行一个**，用 `|` 分隔，
第一个字段是规格名称，其余用 `key=value`：

```
蓝光原盘 | resolution=1080[pi] | quality=REMUX | size=>20
中字4K | resolution=2160p | include=中字
```

可用的键：

| 键 | 含义 | 匹配对象 |
| --- | --- | --- |
| `resolution` | 分辨率 | 种子标题 |
| `quality` | 质量（BluRay / WEB-DL / REMUX …） | 种子标题 |
| `effect` | 特效（杜比视界 / HDR / 杜比全景声 …） | 种子标题 |
| `include` | 必须包含 | 标题 + 副标题 + 标签 + 促销信息 |
| `exclude` | 命中则排除 | 同上 |
| `size` | 大小限制，单位 **GB**，支持 `>8`、`<2`、`2-10`、`5`（等价 `>5`） | 种子大小 |

- 同一个键里写多个关键词，用**英文逗号**分隔，插件会转成「或」关系（如 `effect=杜比视界,DOVI`）。
- 所有值都按**正则表达式**处理，所以 `1080[pi]`、`Dolby[\s.]+Vision` 这类写法直接可用。
- 自定义规格的名称如果和预设重名，会以预设为准（自动去重）。

## 4. 工作原理

```
定时触发（跟随系统或固定周期）
   └─ 对每个被接管的订阅：
        ├─ 读取订阅自己的：订阅站点 / 过滤规则组 / 包含 / 排除 / 自定义识别词
        ├─ 取出该订阅的规格（单独配置优先，否则用默认规格）
        ├─ 调用主程序搜索链 SearchChain.process()（一次搜索，拿回全部候选）
        └─ 对该订阅的每一个画质规格：
             ├─ 用 TorrentHelper.filter_torrent() 按该规格过滤候选
             ├─ 电视剧先按「开始集数 ~ 总集数」过滤，范围之外的种子直接跳过
             ├─ 和该规格自己的已下载记录比对（种子去重键 + 电视剧按集）
             ├─ 再和该订阅的整体下载记录比对（跨规格去重，同一种子只下一次）
             ├─ 调用 DownloadChain.download_single() 下载
             │    · 电影：每个规格只下第一个未下载过的（除非开启「下载所有匹配资源」）
             │    · 电视剧：按集记录，多个整包会自动拼齐缺失的集，只下缺的集
             └─ 把种子/集数写进插件自己的进度记录（与媒体库无关）
```

- **进度记录**存在插件数据里（`progress`），格式：`{订阅ID: {规格名: {torrents: [...], episodes: [...]}}}`。
- **跨规格去重**存在插件数据里（`downloaded`），格式：`{订阅ID: [种子去重键, ...]}`。
- **下载记录**存在插件数据里（`history`），详情页可看，最多保留 500 条。
- **最近一次运行结果**存在插件数据里（`last_result`），详情页顶部会显示，
  例如「本次新增 2 个下载任务；某某剧 新增 2 个任务」；如果什么都没做，也会写明原因
  （如「没有选择任何画质规格」）。
- 想重新下载：详情页点「清空记录」，或在「插件数据」里清掉 `progress` / `downloaded`。

## 5. 常见问题

**Q：我点了「保存后立即运行一次」，但好像没反应？**
A：先看详情页顶部的「最近运行结果」，它会直接告诉你原因（最常见的是没勾画质规格、或没选订阅）。
再看 MoviePilot 日志里 `多版本订阅：` 开头的行，每个规格的匹配情况都会打印。
另外「立即运行一次」是保存后延迟 3 秒执行的，稍等一下即可。

**Q：为什么我的订阅变成「暂停」了？**
A：开启了「接管订阅」。这是故意的——原生订阅搜索会自己下一个版本，和插件重复。点详情页「恢复订阅状态」即可还原。

**Q：执行周期在哪里设置？**
A：默认「跟随系统」：取 MoviePilot「设置 → 订阅」里「订阅搜索间隔」与「RSS 间隔」中更短的一个
（所以你填的 RSS 间隔 5 分钟就会生效）。改完系统设置后重新保存一次插件配置即可生效；
也可以在插件里直接选固定周期（5 分钟 ~ 24 小时）。

**Q：会不会重复下载？**
A：不会。每个规格独立记录已下载的种子（去重键 = `站点|种子标题`）与已下载的集数，
同一个订阅下还会再做一次跨规格去重，重复运行会跳过。
除非你开启「同一规格下载所有匹配资源」（即使开启，同一种子也不会下两遍）。

**Q：一个 4K 杜比视界的发行，我同时勾了「4K」和「杜比视界」，会下两份吗？**
A：不会，同一种子在一个订阅里只会下一次。
**想「4K + 杜比视界 + 60FPS 同时满足」算一个版本**，请用「组合规格」写 `4K+DV+60FPS`。

**Q：可以让每个剧用不同规格吗？**
A：可以。保存订阅列表后重新打开配置页，给每个订阅单独勾选「单独规格」；留空的订阅使用「默认画质规格」。

**Q：我的订阅从第 40 集开始，插件会下前面的集吗？**
A：不会。插件只认订阅的「开始集数 ~ 总集数」，范围外的单集或合集都会被跳过（v1.2.0 修复）。

**Q：下载的文件会入库/刮削吗？**
A：本插件只负责「加下载任务」，入库/刮削仍然走 MoviePilot 的整理逻辑。要「下载后即删除、不入库」，请把「保存目录」设成一个**不在媒体库目录里**的目录，并配合 `TorrentRemover`、`AutoClean` 之类的清理插件，或开启本插件的「下载完成后自动删除任务及文件」。

**Q：为什么 4K 规格什么都没下？**
A：可能是站点没有匹配的资源，或者自定义规格里 `size=>8` 之类的限制太严。看详情页的「最近运行结果」和日志里 `多版本订阅：` 开头的行。

**Q：电视剧整包和分集混着出，会重复下吗？**
A：不会。插件按「集」记账：先下了 1-5 集的包，再来 1-12 集的包，只会补下 6-12 集，
且不会超过订阅的「开始集数 ~ 总集数」范围。

**Q：怎么手动跑一次？**
A：详情页点「立即运行」，或使用命令 `/mvsub`。

## 6. 版本记录

- **v1.2.0**：新增**组合规格**（`4K+DV+60FPS`，条件同时满足才算一个版本）；
  支持**每个订阅单独配置规格**（留空用默认规格）；电视剧严格按订阅「开始集数 ~ 总集数」过滤；
  执行周期改为「跟随系统」取「订阅搜索间隔」与「RSS 间隔」中**更短**的一个，也可直接选固定周期。
- **v1.1.0**：画质规格改为**预设多选**（可直接勾选 1080p / 4K / 杜比视界 等），保留自定义规格补充；
  执行周期改为**跟随系统**「订阅搜索时间间隔」，不再需要填 cron；
  新增**跨规格去重**（同一订阅下同一种子只下一次）；详情页新增「最近运行结果」诊断。
- **v1.0.0**：首个版本。多规格独立搜索与下载、独立进度记录、可接管订阅、可选自动删除。
